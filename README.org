#+title: pirc — ~/.pi

This checkout is my live Pi config: settings, packages, themes, keybindings, extensions, and global agent rules. It is not an app.

* Start here

- =docs/PROJECT.org= — context and decisions
- =docs/TODO.org= — work log
- =AGENTS.md= — rules for changing this repo
- =agent/= — live Pi config

* Skills

User-managed skills live in =~/.agents/skills=. Do not put copies in =agent/skills/=. Ponytail loads from its package; pi-lens injects its own.

* Extensions

Local, under =agent/extensions/=. Packages live in =settings.json=, not here.

- =agy-provider= — routes Gemini through the local Antigravity CLI
- =clear-alias= — =/clear= starts a new session
- =clock= — timestamps after user and assistant messages
- =compact-tools= — tool-call display density (ctrl+b)
- =effort-alias= — =/effort= sets thinking level
- =herdr-fork= — =/herdr-fork [focus]= clones this session into a new Herdr worktree workspace (the arg is both the branch slug and the clone's manual =/compact= prompt)
- =inline-skills= — expands =$skill= mentions in a normal prompt
- =ntfy= — ntfy ping when a TUI turn is slow or the session quits (host topic =pi=, Jolo topic =jolo=)
- =pi-official-subagent= — loads Pi's bundled subagent extension
- =pi-vim-jk= — jk to NORMAL; edge j/k walks prompt history
- =theme-toggle= — alt+shift+d flips latte/mocha
- =usage= — two-line usage and cost footer

Changes are live after =/reload= or a new session. Secrets, sessions, caches, and installed packages stay local and gitignored.
